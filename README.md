# Brew & Bean ☕

A responsive coffee shop landing page built using HTML and CSS, featuring a warm café-inspired design, product highlights, and contact information.

🌐 **Live Demo:** https://rhidhimachhabra.github.io/brew-and-bean/

## Overview

Brew & Bean is a frontend website concept for a coffee shop. It showcases the café's identity, featured products, brand story, and contact information through a multi-section landing page.

## Features

- Café-themed homepage with a hero section and call-to-action buttons.
- Navigation links to different website sections.
- About Us section introducing the café.
- Menu section featuring product images, descriptions, and prices.
- Our Story section.
- Contact section with contact details, opening hours, and a contact form interface.
- Footer with quick navigation and social media links.
- Mobile layout tested using Chrome DevTools at a 440px viewport width.
  
**Note:** The contact form is currently a frontend interface and is not connected to a backend or message-submission service.

## Technologies Used

- HTML5
- CSS3
